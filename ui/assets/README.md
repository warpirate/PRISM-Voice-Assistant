# Assets Directory

Place the following assets here:

- `icon.png` - Main application icon (256x256 or larger)
- `icon.ico` - Windows icon file
- `tray-icon.png` - System tray icon (16x16 or 32x32)

You can create these icons using tools like:
- https://www.favicon-generator.org/
- https://convertio.co/png-ico/
- Or use any image editor

For a quick start, you can use a simple circular gradient image as the icon.
